#  Netflix Movie Data Analysis

##  Overview

This project focuses on analyzing Netflix movies and TV shows using **Python and Data Analysis techniques**. The dataset is explored to understand content distribution, genres, release years, ratings, countries, and other interesting trends available on Netflix.

## 🚀 Features

*  Exploratory Data Analysis (EDA)
*  Analysis of Movies and TV Shows
*  Country-wise content analysis
*  Year-wise content trends
*  Rating analysis
*  Genre analysis
*  Data visualization
*  Finding useful insights from Netflix data

##  Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

##  Project Structure

```text
movie-data-analysis-netflix/
│
├── Netflix_Data_Analysis.ipynb
├── netflix_titles.csv

```

##  Analysis Performed

The project analyzes questions such as:

* What type of content is more common on Netflix — Movies or TV Shows?
* How has Netflix content changed over the years?
* Which countries produce the most Netflix content?
* What are the most common genres?
* Which ratings are most frequently available?
* How many movies and TV shows were added in different years?
* What insights can be obtained from the Netflix dataset?

##  Key Insights

The analysis uses different charts and visualizations to identify patterns and trends in Netflix content.

##  How to Run

1. Clone or download this repository.
2. Open the `.ipynb` file in **Google Colab**.
3. Make sure the dataset is available in the correct location.
4. Install the required Python libraries if needed.
5. Run the notebook cells to perform the analysis.

##  Project Objective

The main objective of this project is to practice **Data Analysis, Exploratory Data Analysis (EDA), Data Visualization, and extracting meaningful insights from real-world Netflix data**.
